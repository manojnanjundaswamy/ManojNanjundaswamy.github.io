Privacy Policy

Media Studio Uploader · last updated 23 November 2026

What this is

Media Studio Uploader (the "Tool") is a private desktop tool, run by Manoj Nanjundaswamy, that uploads videos to YouTube channels owned by its operator. The Tool uses YouTube API Services.

YouTube and Google

By using the Tool you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Information the Tool accesses

  • Basic channel details (channel ID and title), to confirm which channel was authorised.
  • Permission to upload videos, set thumbnails and captions, and update titles and descriptions on that channel.
  • Read-only YouTube Analytics for that channel (views, watch time, average view duration, subscribers gained), to see how the operator's own videos perform.
  • Comments on the operator's own videos, so the operator can read and reply to them.
  • Public information about other channels and videos (titles, view counts, upload dates), and public search results, for content research.

The Tool does not read viewing history, subscriptions, contacts, payment details or any private data of other users.

How information is used and stored

The authorisation token issued by Google is stored only on the operator's own computer and is used only for the operator's own channels. Channel ID and title are kept in a local list of authorised channels. Analytics, comments and public channel or video data are displayed on the operator's screen when requested and are not stored; nothing is kept for longer than 30 days. Nothing is sent to any server other than Google's.

Sharing

No information obtained through the YouTube API Services is shared with, sold to or disclosed to any third party.

Cookies

The Tool is a command-line program. It does not place cookies or use any tracking on devices.

Deleting data and revoking access

Access can be revoked at any time on the Google security settings page. When access is revoked, the stored token stops working and is deleted from the computer; channel details are deleted within 7 days. You can also email a deletion request (below) and it will be completed within 7 days.
